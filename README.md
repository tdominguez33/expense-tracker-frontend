# Correr proyecto

### Desarrollo

1. Instalar dependencias
```bash
npm install
```

2. (Opción 1) Ejecutar frontend directamente desde Angular
```bash
npm start
```

3. (Opción 2) Ejecutar frontend como app de escritorio (Tauri)
```bash
npm run tauri:dev
```

### Compilar app de escritorio
```bash
npm run tauri:build
```
